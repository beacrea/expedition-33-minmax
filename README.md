# Expedition 33 Build Reference

A mobile-friendly HTML reference for Clair Obscur: Expedition 33 attribute allocation, Picto/Lumina priorities, and per-character build notes.

## Usage
Open `index.html` directly, or enable GitHub Pages (Settings > Pages > Source: main branch, root) to host it live.

On iOS: open the hosted link in Safari, tap Share, then "Add to Home Screen" for an app-like shortcut.
